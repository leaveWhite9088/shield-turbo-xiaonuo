# 计分公式与深水区红队考核细则（docs/scoring.md）

本基准满分 **100 分**，由 **70 分脚本实测客观分（A30 + B15 + C25）** 与 **30 分匿名补丁盲评分（D30）** 组成。所有阈值参数统一由 `configs/benchmark.json` 驱动。

---

## 1. A 性能压榨得分（满分 30 分）

在同一评测机上，使用相同确定性高压数据集测量深度劣化的初始原版基准与选手沙盒表现：

1. **A1 批量与复杂检索提速比（12 分）**：
   - 设真实物理加速倍数 $S = T_{\text{base}} / T_{\text{cand}}$，最小起评点 $S_{\min} = 1.05$，满分锚点 $S_{\text{target}} = 30.0$：
     $$\text{A1}_{\text{raw}} = 12 \times \text{clamp}\left(\frac{\ln(S / S_{\min})}{\ln(S_{\text{target}} / S_{\min})}, 0, 1\right)$$
2. **A2 高并发读写混合吞吐与尾延迟（10 分）**：
   - 吞吐加速子项（5 分）：多线程读写混合吞吐比 $R = \text{RPS}_{\text{cand}} / \text{RPS}_{\text{base}}$，按对数曲线插值（$18\times$ 满分）；
   - 并发读 P95 尾延迟子项（5 分）：$\text{P95} \le 15\text{ms}$ 得满分，$\ge 220\text{ms}$ 得 0 分，中间按对数插值；
   - **一把全局大锁退化惩罚**：跨租户重写并发干扰探针下，若无关租户轻量读 P80 延迟 $\ge 25\text{ms}$ 且相对无干扰读膨胀倍数 $\ge 2.5\times$，按膨胀比施加 `[0.35, 0.75]` 退化折算系数。
3. **A3 查询放大削减与内存峰值控制（8 分）**：
   - SQL 语句执行削减率（4 分）：基于数据库底层回调统计真实执行条数，削减率 $\ge 90\%$ 满分；
   - 流式导出内存峰值下降率（4 分）：统计多租户大载荷审计摘要导出峰值内存，下降率 $\ge 78\%$ 满分。

## 2. B 业务守恒与效率得分（满分 15 分）

1. **B1 业务输出零失真守恒（5 分）**：
   - 在 58 项多租户复杂读写操作序列（含利益冲突隔离墙过滤与同批次滑动窗口依赖）上逐项比对确定性输出，设精确一致率为 $\text{acc} \in [0, 1]$：
   - 当 $\text{acc} = 1.0$ 时守恒系数 $K = 1.0$，得 `5.00` 分；当 $\text{acc} < 1.0$ 时 $K = \text{acc}^4$，$\text{B1} = 5.0 \times K$，且 **`A` 层全部得分同步乘以 $K$ 强力封顶**。
2. **B2 端到端优化耗时（10 分）**：
   - 墙钟分钟数 $m \le 8.0$ 得原始满分 `10.0`，超出后按 `10.0` 分钟半衰期衰减：$\text{B2}_{\text{raw}} = 10.0 \times 2^{-(m - 8.0)/10.0}$；
   - 质量得分率封顶与守恒封顶：
     $$\text{B2} = \min\left(\text{B2}_{\text{raw}}, 10.0 \times \min\left(1.0, \frac{A + C}{55.0}\right)\right) \times K$$

## 3. C 深水区红队安全攻防得分（满分 25 分）

针对常规漏洞及“因性能优化而引入的新型并发/缓存/原子性漏洞”执行三波共 15 项实弹轰炸：

1. **C1 边界防御、利益冲突隔离墙与并发缓存毒化拦截（9.0 分）**：
   - 多参数动态查询与导出盲注拦截（1.5 分）
   - 多编码、嵌套剥离、反斜杠与空字节路径穿越拦截（1.5 分）
   - 调试参数、内部诊断端点与畸形类型异常响应零密钥泄露（1.5 分）
   - 横向跨租户、纵向跨密级及**部门利益冲突隔离墙（Chinese Wall）双路穿透**（含同密级不同部门员工共享缓存串味刺探）（2.0 分）
   - 动态隔离规则实时生效 + **高并发“撤回权限 vs 慢读回填”竞态毒化轰炸**（2.5 分）
2. **C2 并发穿盾、并发重放与批次/类型混淆攻击防御（8.0 分）**：
   - 30 路屏障同步抢扣稀缺配额、30 路核销单次令牌，及负数刷配额、布尔值冒充整数绕过拦截（3.0 分）
   - 签名伪造、滞后/超前时间戳重放，及 **12 路并发相同流水号齐射回调重放**拦截（2.5 分）
   - **部分失败批次（末尾格式非法或主键冲突）的数据库与内存滑动窗口双原子回滚验证**，及超 64 位整数溢出炸服与非有限浮点（`NaN`/`Infinity`）比较绕过拦截（2.5 分）
3. **C3 抗多变体复杂度炸弹与缓存穿透雪崩护盾（8.0 分）**：
   - 多变体正则回溯炸弹（嵌套量词、重叠交替分支、多通配链）毫秒级拒绝（2.0 分）
   - 千层原始 JSON 括号栈炸弹、深层规则树与宽扇出节点膨胀树毫秒级拒绝且零 500 崩溃（2.0 分）
   - 负值全表扫描（`limit=-1`）、零/超大分页、负偏移、超多词项与通配符泛洪毫秒级拒绝（1.5 分）
   - **100% 穿透查询结果缓存的随机合法查询洪泛**快速响应（`<= 18ms`）及攻击并发期间正常租户请求 P95 护盾（`<= 60ms`）（2.5 分）
