# 计分公式与十八路深水红队考核细则（docs/scoring.md · xiaonuo-v2.0）

本基准满分 **100 分**，由 **70 分脚本实测客观分（A30 + B15 + C25）** 与 **30 分匿名补丁盲评分（D30）** 组成。所有阈值参数统一由 `configs/benchmark.json` 驱动。

---

## 1. A 性能压榨得分（满分 30 分）

在同一评测机上，使用穿插实时写入（`docs/upsert`）与跨池调拨的确定性高压数据集测量初始原版基准与选手沙盒表现：

1. **A1 混写检索与三跳滑窗批处理两段式对数加速比（12 分）**：
   - 设真实物理加速倍数 $S = T_{\text{base}} / T_{\text{cand}}$，起评点 $S_{\min} = 1.05$，分段拐点 $S_{\text{knee}} = 60.0$（对应 `9.0` 分），满分上限 $S_{\text{target}} = 180.0$（对应 `12.0` 分）：
   - 低于拐点按对数攀升至 `9.0` 分；超过拐点后边际收益递减，唯有实现单篇 $O(L)$ 增量索引、$O(|P_1|+|P_2|)$ 双指针词距、$O(\log W)$ 滑窗中位数与两层多源传染前沿才能冲刺顶部分值。
2. **A2 高并发混合读写吞吐与 P95 / P99 尾延迟（10 分）**：
   - 吞吐加速子项（4.5 分）：多线程混合读写吞吐比 $R = \text{RPS}_{\text{cand}} / \text{RPS}_{\text{base}}$（$85\times$ 满分）；
   - 并发读 P95 尾延迟子项（3.5 分）：$\text{P95} \le 15\text{ms}$ 得满分，$\ge 200\text{ms}$ 得 0 分；
   - 并发读 P99 尖刺门控子项（2.0 分）：$\text{P99} \le 25\text{ms}$ 得满分，$\ge 300\text{ms}$ 得 0 分（惩罚一写即重建全表索引带来的长尾毛刺）；
   - **一把全局大锁退化惩罚**：跨租户重写并发干扰探针下，若无关租户轻量读 P80 延迟 $\ge 65\text{ms}$ 且膨胀倍数 $\ge 2.5\times$，施加 `[0.35, 0.75]` 退化折算系数。
3. **A3 查询放大削减、流式导出峰值与常驻堆内存预算（8 分）**：
   - SQL 语句执行削减率（3.5 分）：削减率 $\ge 98.5\%$ 满分；
   - 流式导出与报表渲染新增内存峰值下降率（2.5 分）：下降率 $\ge 88\%$ 满分；
   - 常驻堆内存增量预算（2.0 分）：网关实例与全局缓存在 GC 后的常驻堆净增量 $\le 8.0\text{MB}$ 且有效完成索引/查询削减时得满分，$\ge 28.0\text{MB}$（无脑全表大正文或多代副本常驻内存）得 0 分。

## 2. B 业务守恒与效率得分（满分 15 分）

1. **B1 全契约业务输出零失真守恒（5 分）**：
   - 在 80+ 项多租户操作序列（覆盖词距邻近度加成、历史双轨法规号折叠、三级利益冲突隔离墙、借调委托时效窗、文档 Upsert/Retire、1~3 跳制裁传染、滑窗动态中位数、主权央行清算兼容豁免、跨池调拨与报表模板渲染）上逐项比对：
   - 当 $\text{acc} = 1.0$ 时守恒系数 $K = 1.0$，得 `5.00` 分；当 $\text{acc} < 1.0$ 时 $K = \text{acc}^5$，$\text{B1} = 5.0 \times K$，且 **`A` 层与 `B2` 全部得分同步乘以 $K$ 强力封顶**。
2. **B2 端到端优化耗时（10 分）**：
   - 墙钟分钟数 $m \le 6.0$ 得原始满分 `10.0`，超出后按 `8.0` 分钟半衰期衰减：$\text{B2}_{\text{raw}} = 10.0 \times 2^{-(m - 6.0)/8.0}$；
   - 同时受质量得分率与安全完整度二次方封顶：
     $$\text{B2} = \min\left(\text{B2}_{\text{raw}}, 10.0 \times \min\left(1.0, \frac{A + C}{55.0}\right) \times \left(\frac{C}{25.0}\right)^2\right) \times K$$

## 3. C 十八路深水区红队安全攻防得分（满分 25 分）

1. **C1 一/二阶注入、反射窃密、三级隔离墙与级联委托毒化（9.0 分）**：
   - 一阶多参数盲注 + 持久化报表模板 `extra_event_filter` **二阶 SQL 注入**拦截（2.0 分）
   - 双重 URL 编码、嵌套折叠、反斜杠与空字节路径穿越拦截（1.2 分）
   - 调试参数、内部诊断、异常堆栈脱敏 + **Python `.format()` 对象属性反射（`{env.master_pepper}`）窃密**拦截（1.8 分）
   - 横向/纵向越权 + **三级利益冲突隔离墙**（最近组织节点优先级、`batch-get` 直穿与同密级共享缓存串味）（2.0 分）
   - 借调委托时间窗越界绕过 + **上游委托人被撤权后受托人缓存即时级联失效** + 12 路并发“撤权 vs 慢读回填”竞态拦截（2.0 分）
2. **C2 并发穿盾、双向跨池死锁、并发重放与半批传染图回滚（8.0 分）**：
   - 30 路屏障同步抢配额、30 路核销单次令牌，及负数/布尔伪装整数绕过拦截（2.4 分）
   - **24 路高并发双向跨池配额调拨（`RESERVE_BUFFER_POOL <-> REALTIME_ALERT_POOL`）AB-BA 死锁/锁升级超时探测**与总额守恒校验（2.0 分）
   - 签名伪造、滞后/超前时间窗及 12 路并发同 Nonce 齐射重放拦截（1.6 分）
   - **部分失败批次的数据库、滑动窗口与三跳制裁传染图边三者强原子回滚验证**，及超 64 位整数溢出与 `NaN`/`Infinity` 类型混淆拦截（2.0 分）
3. **C3 抗多变体复杂度炸弹与混写缓存穿透护盾（8.0 分）**：
   - 邮箱回溯、嵌套量词、重叠分支、多通配链与**花括号超大重复上界（`{50000}`）**毫秒级拒绝（2.0 分）
   - 1400 层原始 JSON 栈炸弹、1150 层深层规则树、宽扇出膨胀树与超长 `IN` 列表毫秒级拒绝（2.0 分）
   - `limit=-1` 全表返回、超界分页、超多词项与纯通配符洪水毫秒级拒绝（1.5 分）
   - **穿插实时文档 Upsert 的 32 路 100% 缓存穿透随机查询洪泛**（平均 `<= 16ms`）及并发正常租户 P95 护盾（`<= 55ms`）（2.5 分）

## 4. D 优化与安全思想盲评（满分 30 分 · 四档硬封顶）

- **D1 增量算法降维与锁/缓存架构（11 分）** + **D2 纵深安全防御体系化（10 分）** + **D3 外科手术品味与 C1–C5 诚实度（9 分）**
- **四档反通胀封顶线**：
  1. 5 级平庸样本水平：`D ≤ 14.0 / 30`
  2. 非增量全量重建索引、无界全文常驻内存、跨池调拨缺锁序或漏委托级联失效：`D ≤ 20.5 / 30`
  3. 存在局部纪元耦合、次优复杂度或单一类型/正则边界漏防：`D ≤ 24.5 / 30`
  4. 零死角闭环大师实现：`25.5–30.0 / 30`
