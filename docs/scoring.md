# 计分公式与二十路深水红队考核细则（docs/scoring.md · xiaonuo-v3.0）

本基准满分 **100 分**，由 **70 分脚本实测客观分（A32 + B10 + C28）** 与 **30 分匿名补丁盲评分（D30）** 组成。所有阈值参数统一由 `configs/benchmark.json` 驱动。

---

## 1. A 性能压榨得分（满分 32 分）

在同一评测机上，使用穿插高频实时写入（`docs/upsert`）、文档隔离翻转（`docs/quarantine`）、动态隔离墙切换（`admin/doc-acl`）与跨池调拨的确定性高压数据集测量初始原版基准与选手沙盒表现：

1. **A1 混写检索与三跳滑窗批处理两段式对数加速比（13.0 分）**：
   - 设真实物理加速倍数 $S = T_{\text{base}} / T_{\text{cand}}$，起评点 $S_{\min} = 1.05$，分段拐点 $S_{\text{knee}} = 95.0$（对应 `8.5` 分），满分上限 $S_{\text{target}} = 260.0$（对应 `13.0` 分）；
   - 低于拐点按对数攀升至 `8.5` 分；超过拐点后边际收益递减，唯有实现单篇 $O(L + \text{deg})$ 双向引用增量倒排、$O(|P_1|+|P_2|)$ 双指针短路词距、$O(\log W)$ 滑窗中位数与两层多源传染前沿才能冲刺顶部分值。
2. **A2 高并发混合读写吞吐与 P95 / 高权重 P99 尾延迟（11.0 分）**：
   - 吞吐加速子项（4.5 分）：14 线程混合读写吞吐比 $R = \text{RPS}_{\text{cand}} / \text{RPS}_{\text{base}}$（$115\times$ 满分）；
   - 并发读 P95 尾延迟子项（3.0 分）：$\text{P95} \le 10\text{ms}$ 得满分，$\ge 180\text{ms}$ 得 0 分；
   - 并发读 P99 尖刺门控子项（3.5 分）：$\text{P99} \le 18\text{ms}$ 得满分，$\ge 260\text{ms}$ 得 0 分（重罚单篇写入或修改单条 ACL 即重建整租户索引带来的长尾毛刺）；
   - **一把全局大锁退化惩罚**：跨租户重写并发干扰探针下，若无关租户轻量读 P80 延迟 $\ge 55\text{ms}$ 且膨胀倍数 $\ge 2.4\times$，施加 `[0.35, 0.75]` 退化折算系数。
3. **A3 查询放大削减、流式导出峰值与常驻堆内存预算（8.0 分）**：
   - SQL 语句执行削减率（3.0 分）：削减率 $\ge 99.0\%$ 满分；
   - 流式导出与报表渲染新增内存峰值下降率（2.2 分）：下降率 $\ge 90.0\%$ 满分；
   - 常驻堆内存增量预算（2.8 分）：网关实例与全局缓存在 GC 后的常驻堆净增量 $\le 4.5\text{MB}$ 且有效完成索引/查询削减时得满分，$\ge 18.0\text{MB}$（无脑全表大正文或多代副本常驻内存）得 0 分。

## 2. B 业务守恒与效率得分（满分 10 分）

1. **B1 跨模块全契约业务输出零失真守恒（5.0 分）**：
   - 在 95+ 项多租户操作序列（覆盖词距邻近度加成、历史双轨法规号折叠、跨文档内部 `doc_` 有效引用随隔离/退役动态剥离与恢复、三级利益冲突隔离墙、1~2 跳受控借调双窗口交集与上游到期降级、第 3 跳阻断、1~3 跳制裁传染、滑窗动态中位数、主权央行清算兼容豁免、高危 `REJECT` 实时告警配额耗尽与跨池调拨补给联动、报表模板渲染与滚动哈希）上逐项比对：
   - 当 $\text{acc} = 1.0$ 时守恒系数 $K = 1.0$，得 `5.00` 分；当 $\text{acc} < 1.0$ 时 $K = \text{acc}^5$，$\text{B1} = 5.0 \times K$，且 **`A` 层与 `B2` 全部得分同步乘以 $K$ 强力封顶**。
2. **B2 端到端优化耗时（5.0 分）**：
   - 墙钟分钟数 $m \le 8.0$ 得原始满分 `5.0`，超出后按 `22.0` 分钟温和半衰期衰减：$\text{B2}_{\text{raw}} = 5.0 \times 2^{-(m - 8.0)/22.0}$；
   - 同时受质量得分率与安全完整度二次方封顶：
     $$\text{B2} = \min\left(\text{B2}_{\text{raw}}, 5.0 \times \min\left(1.0, \frac{A + C}{60.0}\right) \times \left(\frac{C}{28.0}\right)^2\right) \times K$$

## 3. C 二十路深水区红队安全攻防得分（满分 28 分）

1. **C1 双通道二阶注入、反射放大、跨租户侧信道与二级委托毒化（10.0 分）**：
   - 一阶多参数盲注 + **双通道二阶持久化 SQL 注入**（报表模板 `extra_event_filter` + 文档 `docs/upsert` 内部引用 `citations`）（2.2 分）
   - 双重 URL 编码、混合编码、嵌套折叠、反斜杠与空字节路径穿越拦截（1.3 分）
   - 调试参数、内部诊断、异常堆栈脱敏 + **Python `.format()` 属性/下标反射窃密与 `:0>200000` 超宽格式说明符内存放大**拦截（1.8 分）
   - 横向/纵向越权 + 三级利益冲突隔离墙 + **跨租户内部文档引用存在性侧信道预言机**拦截（2.2 分）
   - 1~2 跳借调窗口越界绕过 + **上游一级窗口自然到期（零写操作）下游缓存即时降级** + 第 3 跳阻断 + 源头撤权级联失效 + 14 路并发“撤权 vs 慢读回填”竞态拦截（2.5 分）
2. **C2 并发穿盾、跨模块交叉死锁、并发重放与四位一体强原子回滚（9.0 分）**：
   - 32 路屏障同步抢配额、32 路核销单次令牌，及负数/布尔伪装整数绕过拦截（2.2 分）
   - **28 路跨模块交叉写竞争（20 路双向 `quotas/transfer` + 8 路含高危 `REJECT` 批次评估抢扣 `REALTIME_ALERT_POOL`）死锁探测**与全局配额总额守恒校验（2.5 分）
   - 签名伪造、滞后/超前时间窗、布尔金额混淆及 16 路并发同 Nonce 齐射重放拦截（1.8 分）
   - **失败批次“数据库 + 滑动窗口 + 三跳传染图边 + `REALTIME_ALERT_POOL` 告警配额”四位一体强原子回滚验证**，及超 64 位整数溢出、`bool` 与 `NaN`/`Infinity` 拦截（2.5 分）
3. **C3 抗全变体复杂度/环路炸弹与混写/动态ACL穿透护盾（9.0 分）**：
   - 邮箱回溯、嵌套量词、重叠分支、多通配链、花括号大上界 `{50000}`、反向引用与**借调委托有向环路 DoS 炸弹**毫秒级防御（2.3 分）
   - 1400 层原始 JSON 栈炸弹、1150 层深层规则树、宽扇出膨胀树、超长 `IN` 列表与 **2000 条文档引用洪水炸弹**毫秒级拒绝（2.0 分）
   - `limit=-1` 全表返回、超界分页、超多词项与纯通配符洪水毫秒级拒绝（1.7 分）
   - **穿插实时文档 Upsert 与动态 `doc-acl` 切换的 36 路 100% 缓存穿透随机查询洪泛**（平均 `<= 15ms`）及并发正常租户 P95 护盾（`<= 50ms`）（3.0 分）

## 4. D 优化与安全思想盲评（满分 30 分 · 五档精细硬封顶）

- **D1 增量算法降维、内存紧凑度与锁/缓存架构（11 分）** + **D2 纵深安全防御体系化（10 分）** + **D3 外科手术品味与 C1–C5 诚实度（9 分）**
- **五档反粘连封顶线**：
  1. **5.0 级平庸样本水平**：`D ≤ 13.5 / 30`
  2. **6.5 级架构硬伤**（非增量全量重建索引、漏反向引用联动、无界全文常驻内存、跨模块锁序隐患、漏二级借调/环路或漏四重回滚/二阶注入）：`D ≤ 19.0 / 30`
  3. **7.5 级局部耦合或次优复杂度**（改单条 ACL 清空文档索引、逐笔排序求中位数、`fetchall` 大列、漏跨租户引用侧信道/宽度放大/数值边界或 C1–C5 夸大）：`D ≤ 23.0 / 30`
  4. **8.5 级优秀但未达极致精细度**（缺集合大小下界剪枝、缺双指针 `min_dist==1` 早停、缺 `reverse_dependents` 局部更新、未用 `__slots__`/未剔除 `body`、缺滑窗乱序保底、缺未知主体常量时间掩蔽或 `json.loads` 后才检深度）：`D ≤ 26.0 / 30`
  5. **9.5 级殿堂零死角闭环大师**：`27.0–30.0 / 30`
